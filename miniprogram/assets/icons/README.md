# TabBar 图标说明

由于微信小程序 TabBar 需要 .png 格式图标文件，请在 `assets/icons/` 目录下放置以下 8 个图标文件：

## 图标清单（推荐尺寸: 81x81 px）

### 首页
- home.png         - 首页图标（灰色，未选中态）
- home-active.png  - 首页图标（蓝色，选中态 #3b82f6）

### 动作库
- exercise.png         - 动作库图标（灰色）
- exercise-active.png  - 动作库图标（蓝色）

### 报告
- report.png         - 报告图标（灰色）
- report-active.png  - 报告图标（蓝色）

### 我的
- profile.png         - 我的图标（灰色）
- profile-active.png  - 我的图标（蓝色）

## 临时方案

如果暂时没有图标，可以在 iconfont.cn 下载免费图标，或使用以下在线工具生成：
- https://www.iconfont.cn/ - 阿里巴巴矢量图标库

在获得图标前，小程序仍可正常运行，TabBar 图标将显示为空。
