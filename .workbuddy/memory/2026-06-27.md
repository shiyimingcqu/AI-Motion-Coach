## 实时检测面板 UI 设计

使用 Ardot 设计了"运动姿态评估与纠错系统"的实时检测面板页面。

**设计系统**:
- 风格: Soft Neumorphism（暗色新拟态）
- 配色: Soft Whoop Warm Orange Dark（#161618 背景 + #FF8C42 暖橙强调色）
- 字体: Geist Bold (标题) + Inter (正文) + Geist Mono (数字)
- 布局: Dark Monitoring Ops Multi Panel Dashboard 改编

**页面布局 (1440×900)**:
- 顶部栏 (56px): REC 指示灯 + 训练名称 + 计时器 + 设置
- 左侧 (60%): 摄像头画面 + 骨架检测叠加图（彩色关节：绿/黄/红表示姿态质量）
- 右侧 (40%): 3 个信息卡片
  - 训练信息卡（深蹲、次数、目标）
  - 姿态评分卡（82 分 + 膝/髋/踝关节角度）
  - 实时纠错卡（错误提示 + 矫正建议）
- 底部栏 (56px): 暂停/重置/切换摄像头按钮
