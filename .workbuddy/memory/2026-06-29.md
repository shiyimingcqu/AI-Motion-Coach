## 多运动实时监测 + DTW 模板评分功能开发

### 完成内容

**1. 为现有 3 个分析器添加 DTW 模板评分**
- `push_up_analyzer.py`: 新增 ErrorCounter、TemplateService、rep 跟踪（_track_rep_motion/_is_rep_finished/_score_completed_rep）。DTW 60% + 关键姿态 30% + 稳定性 10% 评分模式。权重：elbow_angle 0.40, body_line_angle 0.30, hip_sag 0.20, symmetry_diff 0.10
- `jumping_jack_analyzer.py`: 同上模式，phase == "complete" 时触发评分。权重：foot_distance 0.25, avg_arm_height 0.25, avg_arm_angle 0.25, arm_angle_diff 0.15, leg_spread_angle 0.10
- `plank_analyzer.py`: 静态保持动作特殊处理——每 30 帧（~3 秒）周期性 DTW 稳定性评分。hold_frames buffer + _periodic_dtw_score() 方法

**2. 创建 4 个新分析器**（均含完整 DTW 评分）
- `lunge_analyzer.py`（弓步蹲）: knee_angle/hip_angle/trunk_angle/knee_symmetry_diff，阶段 standing→down→bottom→up
- `glute_bridge_analyzer.py`（臀桥）: hip_angle/body_line_angle/hip_height_diff，阶段 lying→lifting→top_hold→lowering
- `high_knees_analyzer.py`（高抬腿）: knee_height/knee_angle/hip_angle/knee_height_symmetry，阶段 stand→lifting→peak→lowering
- `burpee_analyzer.py`（波比跳）: hip_angle/shoulder_angle/body_line_angle/wrist_height，阶段 standing→squat_down→plank→squat_up→jump

**3. 创建 4 个新模板 JSON**
- `lunge_template.json`, `glute_bridge_template.json`, `high_knees_template.json`, `burpee_template.json`
- 修复了 `template_service.py` 的 `_find_template_file` 方法，新增 `{action}_template.json` 匹配模式

**4. 更新注册和定义**
- `registry.py`: ANALYZER_REGISTRY 从 4 扩展至 8
- `exercise_metrics.py`: EXERCISE_CORE_METRICS 新增 4 个动作
- `exercise/registry.py`: EXERCISES 新增 4 个 ExerciseDefinition

**5. 前端更新**
- `training.ts`: exercises 数组新增 lunge/glute_bridge/high_knees/burpee
- `RealtimeDetectView.vue`: DEFAULT_EXERCISE_OPTIONS 新增 4 个动作

## 微信小程序端开发

### 后端改动
- `entities.py`: UserORM 新增 `openid` 字段 (String(64), unique, nullable) + `hashed_password` 改为 nullable
- `auth.py`: 新增 `POST /api/auth/wechat-login`（微信 code → openid → JWT），新增 `WechatLoginRequest` schema
- `realtime.py`: 新增 `POST /api/realtime/pose-detect`（base64 图片帧 → MediaPipe 33 关键点 + 动作特征）

**7 个页面（28 个文件）**:

### 技术架构
- 登录: wx.login() → code → POST /api/auth/wechat-login → JWT → wx.Storage
- 实时检测: Camera 帧 → base64 → POST /api/realtime/pose-detect → 关键点 → WebSocket /api/realtime/pose → 评分
- Canvas 骨架: 前置摄像头镜像 + 归一化坐标映射 + 33 关键点连线
